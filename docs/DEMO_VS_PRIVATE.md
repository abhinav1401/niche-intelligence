# Public demonstration versus private application

| Capability | Public demonstration | Separate private local application |
|---|---|---|
| Data | Frozen fictional fixture and precomputed results | Public YouTube API observations and authorised imports |
| Modes | Public Demo only; cannot switch to Live | Physically separate Demo and Live stores |
| Original research pages | All eight retained with safe exploration | Full dashboard and editing tools |
| Autonomous research | Illustrated eight-stage walkthrough only | User-triggered discovery, selection, collection, checkpoints and resume |
| Research/collection execution | Explicitly rejected; implementations omitted | Official YouTube API client, subject to configured limits |
| API credentials | No loading mechanism, no configured secrets | Private environment-only keys |
| Quota interface | Frozen synthetic ledger illustrating the real UI | Durable atomic daily/minute reservations, alerts, history and provider suspensions |
| Derived metrics | Precomputed synthetic illustrations | Guarded until actual applicable YouTube policy acceptance/permission |
| Historical growth | Synthetic examples; unavailable intervals stay unavailable | Actual observed snapshots only, subject to retention permission |
| Ideas | Frozen curated briefs and safe exports | Local generation, optional configured model expansion, editorial backlog |
| Saving or importing | Not offered; direct calls reject | Manual corrections, reviews, imports, notes and rankings |
| Storage | One immutable bundled synthetic database; no visitor writes | Local SQLite research, snapshots, audit and run state |
| Paid models | Not present | Optional configured providers; separate payment/access required |
| Cloud Monitoring | No integration or credentials | Optional separately authorised read-only integration |
| Scheduling | No jobs or schedules | No automatic future usage unless explicitly arranged by the owner |
| Accounts/subscriptions | None | Not a publicly launched subscription service |

The demonstration reuses real dashboard functions and fixture-derived calculations from source commit recorded in `REUSE_PROVENANCE.json`. The original analytics engines computed the frozen files in an isolated offline build with outbound connections blocked. A visitor does not execute those engines. All synthetic labels are prominent; no fictional performance is attributed to real creators.

A reviewer can understand the proposed methodology and inspect example evidence without access to private research, secrets or the operator's computer. The demonstration does not prove policy acceptance, production readiness of a future commercial service, real market demand, 100-episode capacity or a measured supply gap.
